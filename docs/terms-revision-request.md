## 수정 1. `service-terms.md` 제12조 — 자기모순 해소

**문제**: "영구 보존되는 개인정보는 없습니다" 직후에 "현재 단계에서 회원 탈퇴는 기기 내 정보 삭제, 서비스 로그아웃 및 소셜 로그아웃의 형태로 처리되며..."가 이어져, 사실상 서버 데이터가 남는다는 점과 자기모순됨.

**현재 본문 (제12조 후반부)**:

```
회원 탈퇴 시 데이터 처리는 다음과 같습니다.

- 기기에 저장된 정보(프로필, 일정, 즐겨찾기, 설정 등)는 탈퇴 즉시 해당 기기에서 삭제됩니다.
- 서버에 저장된 프로필 사진은 탈퇴 시 즉시 삭제됩니다.
- 닉네임 선점 기록 및 알림 이력은 재가입 부정이용 방지 등을 위하여 탈퇴 후 90일간 보존된 뒤 파기됩니다.
- 수영장·시간표 제보 데이터는 수영장 정보의 공익적 성격을 고려하여 개인 식별이 불가능하도록 익명화한 후 운영·통계 목적으로 보존될 수 있습니다.
- 영구 보존되는 개인정보는 없습니다.

현재 단계에서 회원 탈퇴는 기기 내 정보 삭제, 서비스 로그아웃 및 소셜 로그아웃의 형태로 처리되며, 회사는 서버 측 계정 및 데이터의 영구 삭제 절차를 추후 도입할 예정입니다. 해당 절차 도입 시 그 내용을 본 약관 또는 개인정보 처리방침을 통해 안내합니다.
```

**수정 후 본문**:

```
회원 탈퇴 시 데이터 처리는 다음과 같습니다.

- 즉시 삭제: 기기에 저장된 정보(프로필, 일정, 즐겨찾기, 설정 등)는 탈퇴 즉시 해당 기기에서 삭제되며, 서비스 로그아웃 및 소셜 로그아웃이 함께 처리됩니다. 서버에 저장된 프로필 사진도 즉시 삭제됩니다.
- 90일 후 파기: 닉네임 선점 기록 및 알림 이력은 재가입 부정이용 방지 등을 위하여 탈퇴 후 90일간 보존된 뒤 파기됩니다.
- 익명화 후 보존: 수영장·시간표 제보 데이터는 수영장 정보의 공익적 성격을 고려하여 개인 식별이 불가능하도록 익명화한 후 운영·통계 목적으로 보존될 수 있습니다.
- 영구 보존: 없습니다.

다만 현재 단계에서는 서버 측 계정 식별자 및 인증 정보의 자동 영구 삭제 절차가 구축 중이며, 해당 절차가 도입되기 전까지 회사는 회원 탈퇴 요청을 받은 후 위 기준에 따라 수동으로 삭제 처리합니다. 자동 삭제 절차 도입 시 그 내용을 본 약관 또는 개인정보 처리방침을 통해 안내합니다.
```

## 수정 2. `location-terms.md` 제4조 — "지도 뷰포트" 용어 풀어쓰기

**문제**: "뷰포트"는 일반 사용자가 이해하기 어려운 개발자 용어.

**현재 본문 (제4조 제3자 제공 단락)**:

```
제3자 제공: 회사는 개인위치정보를 제3자에게 제공하지 않습니다. 다만 지도 화면 표시를 위하여 이용자가 보고 있는 지도 영역의 중심 좌표(지도 뷰포트 좌표로서 기기의 실제 위치와 다름)가 지도 제공 사업자(네이버클라우드 주식회사, 대한민국)에 전달될 수 있으며, 이는 지도 타일 렌더링 목적으로만 이용됩니다.
```

**수정 후 본문**:

```
제3자 제공: 회사는 개인위치정보를 제3자에게 제공하지 않습니다. 다만 지도 화면 표시를 위하여 이용자가 현재 보고 있는 지도 화면의 중심 좌표(이는 지도 영역을 나타내는 좌표이며, 이용자의 실제 기기 위치와는 다릅니다)가 지도 제공 사업자(네이버클라우드 주식회사, 대한민국)에 전달될 수 있으며, 이는 지도 화면 표시 목적으로만 이용됩니다.
```

(변경: "지도 뷰포트 좌표로서" → "이는 지도 영역을 나타내는 좌표이며", "지도 타일 렌더링" → "지도 화면 표시")

## 수정 4. `privacy-policy.md` 제7조 — 본인 확인 절차 보완

**문제**: 권리 행사 시 본인 또는 정당한 대리인 여부 확인 절차가 명시되지 않음. 제3자가 타인 정보 삭제를 요청하는 상황 방지 조항 필요.

**현재 본문 (제7조 말미, "전송요구권 안내" 단락 바로 앞)**:

제7조 마지막 두 단락이 다음과 같이 끝남:

```
회사는 만 14세 미만 아동의 가입을 받지 않으므로 통상적으로 법정대리인의 권리 대리 행사가 발생하지 않으나, 관련 사유가 확인되는 경우 법정대리인은 아동의 개인정보에 대한 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다.

전송요구권 안내: 정보주체는 「개인정보 보호법」 제35조의2에 따라...
```

**수정 지시**: 위 만 14세 단락과 "전송요구권 안내" 단락 사이에 다음 단락을 새로 추가:

```
회사는 권리 행사 요청자가 본인 또는 정당한 대리인인지 확인하기 위하여 관련 자료의 제출을 요청할 수 있습니다. 대리인을 통하여 권리를 행사하는 경우 위임장 등 대리권을 증명하는 서류를 제출하여야 합니다.
```

## 수정 5. 마케팅 동의서 — 향후 발송 시 재안내 명시 (보강)

**파일**: `marketing-consent.md`

**문제**: 정통망법 §50상 광고성 정보 수신 동의는 "수신할 광고성 정보의 유형 및 발송자"가 명시되어야 함. 현재는 발송 인프라·채널·발송자 모두 미확정 상태에서 동의를 받는 구조라, 향후 발송 시작 시점에 별도 안내가 있어야 안전.

**현재 본문 (§2 전송 방식, 두 번째 단락)**:

```
현재 회사는 광고성 정보 발송 인프라를 운영하고 있지 않아 마케팅 정보를 발송하지 않습니다. 본 동의는 향후 발송 인프라가 구축된 이후 발송을 시작하기 위하여 미리 받아 두는 것이며, 실제 발송이 시작되는 시점 및 전송 채널은 서비스 내 안내를 통해 별도로 고지합니다.
```

**수정 후 본문**:

```
현재 회사는 광고성 정보 발송 인프라를 운영하고 있지 않아 마케팅 정보를 발송하지 않습니다. 본 동의는 향후 발송 인프라가 구축된 이후 발송을 시작하기 위하여 미리 받아 두는 것이며, 실제 발송이 시작되는 시점에 회사는 발송 채널, 발송자, 광고성 정보의 유형 및 수신 거부 방법을 서비스 내 공지사항 또는 인앱 알림을 통하여 사전에 안내합니다. 안내 시점에 이용자는 본 동의를 유지하거나 철회할 수 있습니다.
```
