**문제**: 푸시 토큰이 미국 소재 FCM·APNs로 전송되므로 국외 이전이 발생함. 현재 §12는 "Google 계정 로그인 시 본인 인증"만 국외 처리로 명시되어 있음.

**현재 본문 (제12조 국외 이전, 두 번째 단락)**:

```
다만 이용자가 Google 계정으로 로그인하는 경우, 본인 인증 과정에서 Google LLC(미국)를 통한 인증 토큰 검증이 이루어집니다. 이는 이용자가 선택한 로그인 수단에 한하여 인증 목적으로만 처리되며, Kakao 계정 로그인을 이용하는 경우 해당 처리는 발생하지 않습니다.
```

**수정 후 본문** — 다음과 같이 푸시 알림 관련 단락을 추가하여 2개 단락으로 분리:

```

OS 푸시 알림 발송을 위하여 푸시 토큰은 다음과 같이 처리됩니다. Android 기기의 경우 Google LLC가 운영하는 Firebase Cloud Messaging(미국), iOS 기기의 경우 Apple Inc.가 운영하는 Apple Push Notification Service(미국)에 전송되며, 푸시 알림 발송 목적으로만 이용됩니다. 이용자가 OS 푸시 알림 권한을 거부하거나 회원 탈퇴를 하는 경우 푸시 토큰은 즉시 폐기되며, 해당 시점 이후 국외 이전은 발생하지 않습니다.
```
