## 4. 위치정보 처리 — 핵심 차별 포인트

> Pool's day의 위치정보 처리는 **당근마켓 방식과 같으나 더 단순**하다.

### 4.1 처리 방식

- 수집 시점: **앱 사용 중** (지도 화면에서 "내 위치" 버튼 탭, 거리순 정렬, 근거리 추천 시)
- 수집 방법: **OS 위치 권한** (앱 사용 중에만 / "항상 허용" 요구 안 함)
- 저장 위치: **클라이언트 메모리만** — 서버 미전송, 영속 저장 없음
- 파기: 앱 종료 또는 다른 화면 이동 시 즉시 휘발
- 정확도: GPS 기반, 동네 단위 이상 정확
- 보유 기간: **0초** (저장하지 않음)

### 4.2 제3자 제공

- **없음.** 위치정보를 외부에 제공하지 않음.
- 단, 지도 SDK(Naver Maps)가 지도 타일 렌더 시 *지도 중심 좌표*를 Naver Cloud로 전송 — 이는 *기기 위치가 아닌 지도 뷰포트* (사용자가 보고 있는 지도 영역).

### 4.3 위치 권한 거부 시

- 거부해도 서비스 이용 가능. 단, "내 위치" 버튼·거리순 정렬·근거리 추천 기능 비활성화.

### 4.4 약관 작성 지시

위치기반서비스 이용약관에 다음을 명시:
- 수집은 *서비스 제공 시점에 일시적으로* 이루어지며, **보관·로그·이력 일체 없음**
- 위치정보 이용·제공사실 확인자료: **생성·보관하지 않음** (저장 자체가 없으므로)
- 14세 미만 처리 조항: 가입 자체를 받지 않으므로 별도 동의 절차 불필요. 다만 위치정보법 표준 조항은 유지.

## 8. 회원 탈퇴

### 8.1 현재 (P1) 동작

- Settings > 계정 > 회원 탈퇴 → 3단계 확인 모달
- 효과: **로컬 프로필 삭제 + Supabase 로그아웃 + 소셜 로그아웃**
- ⚠️ **현 단계에서는 서버 측 계정 데이터 영구삭제가 미구현** (P2 Edge Function 예정)

### 8.2 약관 작성 지시

약관 § "회원 탈퇴"에는 다음을 모두 명시:
1. 탈퇴 절차 (Settings 메뉴 위치)
2. 탈퇴 시 **즉시 삭제되는 데이터**: 기기 로컬 데이터 전체 (프로필·일정·즐겨찾기 등)
3. **서버에 남는 데이터** (탈퇴 처리 즉시 / 일정 기간 후 / 영구 보존 구분):
   - 즉시 삭제: 아바타 이미지 (Storage), 알림 이력, 닉네임 선점 기록 (2026-06-03 정책: 탈퇴 시 지체 없이 전체 파기 — 구 90일 보존 폐기)
   - 회계·세무 보존(5년): 후원 입금 식별 정보 (국세기본법)
