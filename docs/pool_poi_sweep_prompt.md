# 공공 수영장 누락 색출 — 지도 POI 전수 스윕 프롬프트

> **용도**: 도시/지역 단위로 공공 수영장을 등록할 때, "운영주체 사이트·검색 기반 열거"가 놓치는 풀(다른 운영주체·비전형 명칭: 문화센터·도시공사·복지관·반다비 등)을 **지도 POI 전수검색**으로 빠짐없이 찾아낸다.
> **배경**: 천안 한들문화센터(천안도시공사 운영)를 1차 조사에서 놓침 → 블라인드 `"천안 수영장"` POI 스윕 4번째에 그대로 잡힘을 확인. 발견 누락은 "시간표를 못 구한 것"이 아니라 "풀 존재를 못 찾은 것"이라 POI 스윕이 정공법.

## 절차 (지역 1개당)

1. **POI 전수검색** — 카카오 Local 키워드 API로 `"<지역명> 수영장"` 을 페이지네이션(size=15, page=1..N, `meta.is_end`까지) 끝까지 긁는다. 키는 `.env.local`의 `KAKAO_REST_KEY`(출력 금지). 도시는 구별로도(`"<구> 수영장"`) 한 번씩.
   - 변형 질의도 1회씩: `"<지역명> 국민체육센터"`, `"<지역명> 실내수영장"`, `"<지역명> 문화센터"` (명칭 누락 보강).
2. **공공만 필터** — 결과에서 제외: 사설 강습장/스포츠센터(○○스위밍·○○스포츠클럽 등), 계절 물놀이장, 펜션·주차장·사우나, 대학 전용. 남길 것: 시설관리공단/도시공사/국민체육센터/문화센터/구민·군민체육관/반다비/생활체육센터 등 공공.
3. **등록분과 대조** — prod `pools`에서 `region in (대상지역)` 조회해 이름·주소로 매칭, **미등록 공공풀만** 추린다.
4. **각 미등록 풀 시간표 확보** — 단계: ① `curl -sk -L` 원본 HTML(EUC-KR/cp949 디코드) → ② 첨부 이미지 VLM 판독 → ③ HWP(olefile BodyText zlib+UTF-16LE / HWPX=zip) → ④ 헤드리스 JS 렌더(`scripts/render-js.mjs`, playwright-core ad-hoc 설치). **강습표를 자유수영으로 오인 금지**(별도 자유수영 표/이용안내 자유수영시간만). 공식이 "강습 외 자유수영 레인" 또는 "자유수영 운영시간" 명시 시에만 운영시간 모델로 by_day 도출.
5. **등록** — service_role로 prod 직접 insert(`pool_db_prod_only`). POOL ID는 prod max+버퍼(동시세션 레이스 회피, pre-check 존재여부). 1회 요금 미확인 시 price null. 좌표=`scripts/geocode-kakao.mjs`.
6. **남는 것** — 자유수영 회차가 웹에 정말 없으면(현장 안내판/매표소만) "크리스 캡처 필요"로 분류, 공식 URL 1개 명시.

## 검증 포인트
- 스윕이 **이미 아는 누락(예: 한들)**을 잡는지 먼저 1건으로 확인하고 전역 확대.
- 노이즈(사설·물놀이·펜션) 비율이 높으니 필터가 핵심. POI명에 "수영장"이 없어도 "문화센터/체육관"으로 잡히는 경우 있음.

## 실행 단위 제안
충청 재스윕 대상: 대전 5구 · 세종 · 충북 11시군(청주4구 포함) · 충남 15시군. 도시별 에이전트 1개씩 병렬, 반환=「미등록 공공풀 후보 + 공식 자유수영 URL」.
