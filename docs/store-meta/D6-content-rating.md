# Play Console / App Store — 콘텐츠 등급 (IARC) 답변지

Play Console > **앱 콘텐츠 > 콘텐츠 등급** (IARC 설문 — Play / App Store / IARC 공통)
+ App Store Connect > 앱 정보 > **연령 등급** 동일 답변 기준.

기대 결과: **Everyone (4+)** — 폭력·노출·도박·약물·공포 0.

---

## 카테고리 선택

**유틸리티, 생산성, 커뮤니케이션 또는 기타 (스포츠/소셜)**

- Sports / Lifestyle 카테고리 — 스포츠 콘텐츠 (수영) + 위치 기반 (지도)

---

## IARC 설문 — 표준 12 카테고리

| 카테고리 | 답변 | 비고 |
|---|---|---|
| **폭력** | **아니요** | 사용자 간 폭력 / 게임 폭력 묘사 0 |
| **공포 또는 무서운 콘텐츠** | **아니요** | — |
| **성적 콘텐츠 / 노출** | **아니요** | 수영복 사진은 사용자 업로드 프로필 한정. 운영 검수 안내 정책 (약관) |
| **욕설 / 비속어** | **아니요** | 닉네임 / 자기소개 / 응원 메시지 — 운영자 검수 + 신고 기능 (P3 후속) |
| **도박** | **아니요** | 도박 / 베팅 / 가짜 화폐 0 |
| **약물 / 술 / 담배** | **아니요** | — |
| **자해 또는 자살 묘사** | **아니요** | — |
| **혐오 표현 / 차별** | **아니요** | 닉네임 부적절 시 운영자 차단 + 차단 정책 [[block_policy_enforcement]] |
| **개인 정보 / 위치 정보** | **예 — 정확한 위치는 아님** | 대략적 위치 (현재 위치 주변 풀 검색). 서버 저장 X, 메모리 일시. 약관에 명시 |
| **사용자 간 상호작용** | **예 (제한적)** | 친구 추가 / 일정 초대 / 응원 메시지. 운영자 검수 + 차단 영구. 사용자 간 직접 메시지(채팅) 기능 X |
| **사용자 생성 콘텐츠 표시** | **예** | 닉네임, 자기소개, 응원 메시지, 풀 등록 요청. 모두 운영자 검수 / 신고 가능 |
| **외부 광고** | **아니요** | 광고 / 인앱 광고 0 (광고 없는 정책) |

## 결과 / 등급

| 스토어 | 예상 등급 |
|---|---|
| **Google Play (IARC)** | **모든 연령 (Everyone)** |
| **Apple App Store** | **4+** |
| **ESRB (북미)** | **E (Everyone)** |
| **PEGI (유럽)** | **3+** |
| **GRAC (한국)** | **전체이용가** |

⚠️ **만 14세 이상 가입 게이트**는 앱 자체 정책 (한국 「개인정보 보호법」 만 14세 미만 동의 불가) — IARC 등급 (4+) 과 별개.

스토어 페이지에 "4+ / Everyone" 표시되지만 가입 게이트에서 만 14세 미만 차단. 등록 시 별도 명시 가능.

## 보조 질문 (App Store Connect)

App Store Connect 가 IARC 보다 더 세분화한 질문:

| 질문 | 답변 |
|---|---|
| 만화 또는 판타지 폭력 | 없음 |
| 사실적 폭력 | 없음 |
| 잔인하거나 무자비한 폭력 | 없음 |
| 사회적 약자 / 모욕 | 없음 |
| 성적 또는 노골적인 콘텐츠 | 없음 |
| 음란한 콘텐츠 또는 누드 | 없음 |
| 욕설 또는 저속한 농담 | 없음 |
| 알코올, 담배, 약물 사용 또는 언급 | 없음 |
| 의약품/치료 정보 | 없음 |
| 도박 시뮬레이션 | 없음 |
| 공포 / 무서운 콘텐츠 | 없음 |
| 성숙한 / 시사 풍자 테마 | 없음 |
| 도박 / 콘테스트 | 없음 |
| 무제한 웹 액세스 | 없음 (제한된 외부 링크만) |
| **위치 정보** | **예 — 대략적 위치, 사용자 동의 후 일시적 사용** |
| **사용자 생성 콘텐츠** | **예 — 운영자 검수, 신고 가능** |

---

## 작성 시점

- Play Console > **앱 콘텐츠 > 콘텐츠 등급** 진입 → 위 답변 입력 → IARC 자동 산출 등급 적용
- App Store Connect > 앱 정보 > **연령 등급 편집** 동일 답변
- 출시 전 1회만 답변. 추후 콘텐츠 변경 시 재설문 권장
