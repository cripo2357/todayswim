## C. 각 데이터 유형별 상세 (Play 설문 follow-up)

### 이름 (닉네임)
- 수집 목적: **앱 기능** (사용자 식별, 친구 관계)
- 수집됨: 회원 가입 시 사용자 입력
- 보관 위치: Supabase 서버 + 기기
- 필수/선택: **필수**
- 사용자가 삭제 가능: 예 (회원 탈퇴)
- 전송 중 암호화: 예
- 처리 위탁: Supabase Inc. (DB · 인증), 데이터 저장 한국 서울 리전
- 만 14세 이상

### 이메일 주소
- 수집 목적: **계정 관리**
- 출처: Google / Kakao OAuth 인증 시점 자동 전달
- 보관: Supabase Auth 시스템에만 (별도 복사 X)
- 필수
- 사용자가 삭제 가능: 예

### 사용자 ID (친구 코드)
- 수집 목적: **앱 기능** (친구 추가 식별자)
- 자동 생성 6자 문자열
- 필수
- 사용자가 변경 가능

### 사진 (프로필)
- 수집 목적: **앱 기능** (프로필 표시)
- 출처: 사용자가 직접 업로드 (사진 보관함 선택)
- 보관: Supabase Storage (`avatars` 버킷, 본인 폴더)
- 선택 (기본 아바타로 대체 가능)
- 삭제 가능

### 앱 상호작용 / 화면 진입 (Firebase Analytics)
- 수집 목적: **분석**
- 처리 위탁: Google LLC (Firebase Analytics, 미국)
- 익명 통계만 — 닉네임/이메일/GPS 좌표 미전송
- 선택 (사용자가 OS 광고 ID 재설정으로 거부 가능)

### 진단 / 충돌 로그 (Sentry)
- 수집 목적: **분석 / 앱 기능 (안정성)**
- 처리 위탁: Functional Software Inc. (Sentry, 미국)
- 스택 트레이스, 앱 버전, OS 종류 — IP 자동 수집 비활성
- 로그인 사용자: 친구 코드만 함께 (식별자)
- 선택

### 기기 또는 기타 ID (푸시 토큰)
- 수집 목적: **앱 기능** (OS 푸시 알림)
- 처리 위탁: Google LLC (FCM, 미국) / Apple Inc. (APNs, 미국)
- 회원 탈퇴 시 즉시 폐기, 90일 미사용 자동 정리
- 선택 (사용자가 OS 알림 권한 거부 가능)

### 대략적 위치
- 수집 목적: **앱 기능** (현재 위치 주변 풀 검색)
- 보관 X — 메모리에서만 일시적 사용, 서버 전송 X
- 선택 (앱 사용 가능, 위치 권한 거부해도 기능 작동)
