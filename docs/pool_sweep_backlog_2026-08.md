# 미등록 공공풀 발굴 백로그 (2026-08-03)

전국 229개 시군구 카카오 POI 다차원 스윕(수영장 + 국민체육센터·생활체육센터·체육센터·스포츠센터)
→ 풀신호/공공강신호 필터 + 사설·부속시설 제외 → DB 대조(이름·400m) → 미등록 후보.

**주의**: 각 후보는 "존재 가능성"이지 확정 아님. 등록 전 **①실제 수영장 보유 ②자유수영 일일개방 ③시간표** 개별 검증 필수(근린생활형/면단위 국민체육센터는 체육관+헬스만 있고 풀 없는 경우 있음). 반다비=생활밀착형 국민체육센터(대개 풀 보유, 일부 빙상/체육관).
