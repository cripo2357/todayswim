# 계정 및 데이터 삭제

Pool's day 계정과 데이터는 이용자가 언제든 직접 삭제할 수 있습니다.

## 1. 앱에서 바로 삭제 (권장)

1. Pool's day 앱을 실행합니다.
2. **설정 > 회원 탈퇴**로 이동합니다.
3. 안내에 따라 탈퇴를 완료하면 계정과 관련 데이터가 영구 삭제됩니다.

## 2. 이메일로 요청

앱에 접근할 수 없는 경우 아래 이메일로 요청해 주세요. 본인 확인 후 처리해 드립니다.

📩 **cripo2357@gmail.com** — 메일 제목에 **[계정 삭제]**를 적어주세요.

## 삭제 및 보존되는 데이터

회원 탈퇴 시 처리 내용은 다음과 같습니다.

| 데이터 | 처리 |
|---|---|
| 소셜 로그인 신원·이메일·닉네임·친구코드 | 탈퇴 시 지체 없이 파기 |
| 기기에만 저장된 정보(성별·생년월일·수영 경력 등) | 탈퇴 또는 앱 삭제 시 기기에서 삭제 |
| 프로필 사진 | 탈퇴 시 즉시 삭제 |
| 푸시 알림 토큰 | 탈퇴 시 즉시 폐기 |
| 닉네임 선점 기록·알림 이력 | 재가입 부정이용 방지를 위해 탈퇴 후 90일 보존 후 파기 |
| 후원 응원 메시지 | 탈퇴 시 즉시 삭제 |
| 후원 입금 식별 정보(입금자명·금액·일시) | 「국세기본법」 등 관련 법령에 따라 통상 5년 보존 후 파기 |

자세한 내용은 [개인정보 처리방침](../terms/privacy-policy/)을 참고해 주세요.
