# 일러스트 라이브러리 (앞으로 사용 가능성 있는 후보 37종)

Figma에서 export해 모아둔 **재사용 후보** 일러스트 풀. 화면에 일러스트가
필요하면 **이 폴더 + `assets/illustrations/`(이미 사용 중) 두 곳을 먼저
확인**한다. 새로 export 요청 전에 여기에 맞는 게 있는지 본다.

사용 시: 이 파일은 보존(라이브러리 원본)하고, `assets/illustrations/`로
**복사**하면서 의미명으로 rename. 파일명이 전부 `Frame-N`이라 내용은
아래 표로 찾는다. (썸네일 재생성: `node scripts/catalog-thumbs.mjs` —
sharp 필요, `assets/library/.catalog/`에 시트 PNG 생성. 생성물은 gitignore.)
